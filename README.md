# Agent-Planing

แบบคุยและติดตามแผนทีม B Your Wealth 1 สำหรับ iPad

## เปิด GitHub Pages

Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save

## ใช้งาน

เลือกสมาชิก กรอกแบบฟอร์ม แล้วเก็บรอบที่คุยเข้าประวัติ ข้อมูลบันทึกอัตโนมัติใน localStorage ของเบราว์เซอร์ปัจจุบัน ไม่ซิงก์ข้ามเครื่อง สำรองข้อมูลด้วยปุ่มสำรองข้อมูล และเปิดคืนด้วยปุ่มเปิดไฟล์สำรอง

บันทึก PDF ผ่านปุ่มบันทึก PDF / พิมพ์ แล้วเลือกเมนูแชร์หรือบันทึกลง Files บน iPad

## ข้อมูลตั้งต้น

ชื่อเล่นและผลงานสะสมมาจากภาพ PRP ณ 16 ต.ค. 2569 ที่ผู้ใช้ให้ ยอด FYC L และ FYP L เป็นบาท ตัวเลขตั้งต้นอยู่ในโค้ดสาธารณะ ข้อมูลการคุยที่กรอกภายหลังเก็บเฉพาะในเครื่อง ไม่ส่งขึ้น GitHub

ข้อมูลจากเว็บเดิมจะไม่ย้ายมายัง GitHub Pages อัตโนมัติ ให้สำรอง JSON จากเว็บเดิมแล้วเปิดไฟล์สำรองในเว็บใหม่

## Validation

ตรวจ JavaScript syntax และทดสอบการแยกสมาชิก บันทึกแบบร่าง ประวัติ เริ่มรอบใหม่ และปฏิเสธไฟล์สำรองผิดรูปแบบ ยังไม่ได้ตรวจหน้าจอและ PDF บน Safari iPad จริง
