# Agent-Planing

แบบฟอร์มกลางรายบุคคล B Your Wealth 1 สำหรับให้ตัวแทนกรอกเองแล้วบันทึก PDF ส่งผู้บริหารหน่วย

ไม่มีรายชื่อหรือผลงานของสมาชิกคนอื่นในหน้าเว็บและโค้ดเวอร์ชันปัจจุบัน

## ใช้งาน

เปิดลิงก์ กรอกชื่อ ความพร้อม ข้อจำกัด สิ่งที่อยากฝึก ข้อตกลง 14 วัน และเป้าหมายสิ้นปี แล้วกดบันทึก PDF / พิมพ์

บน iPad ใช้สองนิ้วขยายตัวอย่างในหน้าพิมพ์แล้วกดแชร์ เพื่อบันทึกลงแอปไฟล์หรือส่ง PDF ให้ผู้บริหารหน่วย เว็บไซต์ไม่ส่งคำตอบอัตโนมัติ

แบบร่างเก็บใน localStorage เฉพาะเบราว์เซอร์และอุปกรณ์นั้น ไม่ซิงก์หรือส่งขึ้น GitHub หากใช้เครื่องร่วมกันให้เซฟ PDF แล้วกดล้างแบบฟอร์มก่อนส่งต่อ ไม่ต้องกรอกข้อมูลลูกค้าหรือข้อมูลสุขภาพ

## GitHub Pages

Settings → Pages → Source: Deploy from a branch → main → / (root) → Save

## ตรวจสอบ

ทดสอบ JavaScript syntax การบันทึกแบบร่าง การเรียกพิมพ์ ตรวจวันที่สิ้นสุดก่อนเริ่ม ล้างข้อมูล และตรวจว่าไม่มีข้อมูลตั้งต้นของทีมในโค้ดปัจจุบัน ยังไม่ได้ทดสอบหน้าเว็บและ PDF บน Safari iPad จริง
