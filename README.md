# Agent-Planing

แบบฟอร์มกลางรายบุคคล B Your Wealth 1 ให้ตัวแทนกรอกเองและบันทึก PDF ส่งผู้บริหารหน่วย

## ผลงานและเป้า

กรอกรหัสตัวแทนเพื่อค้นจำนวนเคส FYC L และ FYP L สะสม จากภาพ PRP ที่ผู้ใช้ให้ ณ 16 ต.ค. 2569 ไม่มีการเชื่อมข้อมูลสดกับ AIA รองรับรหัสที่มีเลขศูนย์นำหน้า ไม่มีรายการรายชื่อให้เลือก

เป้าคือ FYC L สะสมสิ้นปี หน่วยบาท ไม่ใช่ยอดเพิ่ม ผลต่าง = max(0, เป้า − FYC L ปัจจุบัน) ความคืบหน้า = FYC L ปัจจุบัน / เป้า × 100 เมื่อเกินเป้าแสดงส่วนเกิน เมื่อเป้าว่างไม่คำนวณ เมื่อเป้าไม่ถูกต้องแจ้งให้แก้

รหัสเป็นเพียงตัวค้นข้อมูล ไม่ใช่ระบบล็อกอิน ชื่อเล่น รหัส และผลงานอยู่ในโค้ดสาธารณะ ผู้ที่ทราบรหัสหรืออ่านโค้ดเข้าถึงข้อมูลตั้งต้นได้

## ใช้งาน

กรอกความพร้อม ข้อจำกัด สิ่งที่อยากฝึก แผน 14 วัน และเป้าหมาย แล้วกดบันทึก PDF / พิมพ์

บน iPad ใช้สองนิ้วขยายตัวอย่างในหน้าพิมพ์แล้วกดแชร์ เพื่อบันทึกลงแอปไฟล์หรือส่ง PDF ให้ผู้บริหารหน่วย เว็บไม่ส่งคำตอบอัตโนมัติ

แบบร่างเก็บใน localStorage เฉพาะเบราว์เซอร์และอุปกรณ์นั้น ไม่ซิงก์หรือส่งขึ้น GitHub หากใช้เครื่องร่วมกันให้บันทึก PDF แล้วล้างแบบฟอร์มก่อนส่งต่อ ไม่ต้องกรอกข้อมูลลูกค้าหรือข้อมูลสุขภาพ
